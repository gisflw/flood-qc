Using the Telemetric Data Downloader:

Update the following files in the "Input" folder:

1. *"paths.txt"*: This file must contain two lines:
   - The first line should specify the input folder path.
   - The second line should specify the output folder path.

2. *"stations.txt"*: Add the stations for data download in a single column format. Each station should be on a separate line, with no spaces, commas, or other delimiters.

3. *"login.txt"*: This file must contain two lines:
   - The first line should include the username.
   - The second line should include the password.
