# Desktop emoji artwork

These PNGs are an unchanged subset of the 72 × 72 artwork from
[Twemoji v16.0.1](https://github.com/jdecked/twemoji/tree/v16.0.1/assets/72x72).

Copyright Twitter, Inc. and other contributors; copyright Jason Sofonia and
Justine De Caires. Graphics are licensed under
[Creative Commons Attribution 4.0 International](LICENSE-GRAPHICS).

The filenames describe their desktop actions. Their Unicode mappings live with
the desktop icon code. HGE branding has separate [provenance](../branding/README.md).
